# Сравнение с npm

Проверено 10.10.2026, npm 12.2.0. npm используется только для сравнения;
приложение не вызывает npm и не читает его lock-файлы или node_modules.

## Этап 4: порядок загрузки

В отдельной пустой папке выполнено:

```console
npm install is-even@1.0.0 is-odd@3.0.1 ansi-styles@6.2.3 --ignore-scripts --no-audit --no-fund --loglevel=http
npm ls --all --unicode=false
```

Порядок нашего DFS postorder при глубине 5:

| Корень | Порядок |
| --- | --- |
| is-even | is-number -> is-odd -> is-even |
| is-odd | is-number -> is-odd |
| ansi-styles | ansi-styles |

Для тестовых данных: цепочка — D C B A; ромб — F E D C B A;
пустой список зависимостей — A; цикл — предупреждение и D C B A.
Для цикла строгий порядок невозможен: A требует B, B требует C, C требует A.

Фактический порядок завершения скачивания архивов в журнале npm:

```text
kind-of@3.2.2
is-number@6.0.0
is-number@3.0.0
is-odd@3.0.1
is-odd@0.1.2
is-even@1.0.0
is-buffer@1.1.6
ansi-styles@6.2.3
```

Это не тот же порядок, что DFS: npm параллельно скачивает архивы,
поэтому время завершения HTTP-запросов не является топологическим порядком.
Например, kind-of скачался раньше is-buffer, хотя зависит от него.
Наш порядок — логический порядок обработки зависимостей, а не расписание сети.
Скрипты установки отключены; сравнивается загрузка архивов и установленное дерево.

## Дерево штатного npm

Фактический результат `npm ls --all --unicode=false`:

```text
+-- ansi-styles@6.2.3
+-- is-even@1.0.0
| `-- is-odd@0.1.2
|   `-- is-number@3.0.0
|     `-- kind-of@3.2.2
|       `-- is-buffer@1.1.6
`-- is-odd@3.0.1
  `-- is-number@6.0.0
```

Граф приложения агрегирован по имени и использует метаданные `latest`.
Например, latest is-odd = 3.0.1, тогда как is-even требует is-odd ^0.1.2.
Поэтому в нашем графе is-even нет kind-of и is-buffer: эти зависимости
относятся к старой версии is-number, выбранной установщиком npm.
Кроме того, latest is-number = 7.0.0, но is-odd требует ^6.0.0.
Число имён в нашей цепочке is-even — 3, в установленной цепочке npm — 5.
Для is-odd набор имён совпадает (2), для ansi-styles совпадает (1).
Приложение не является заменой установщику npm и не моделирует несколько версий,
peer/optional/dev-зависимости, hoisting или выполнение install-скриптов.
Диапазоны берутся из реестра на этапе 2 и не передаются сторонним решателям.
